# Assigment-2-Proglan

## Fungsi
Sistem Informasi Akademik sederhana berbasis terminal yang mengelola data mahasiswa dan nilai menggunakan paradigma pemrograman berorientasi objek.

## Bahasa dan Stack
C++, g++, Make

## Cara Build dan Menjalankan
Kompilasi program:
make

Jalankan program:
./sim_akademik

Kompilasi dan jalankan secara langsung:
make run

## Fitur Utama
- Pencatatan atribut data mahasiswa seperti nama, NRP, dan nilai.
- Pemisahan implementasi logika antara berkas header dan berkas source.
- Otomasi build menggunakan Makefile.
